## FAQ

**Can I showcase repos from an organization I manage?**

Yes! Here are three ways to do it:

1. **Pin them** — On your GitHub profile, you can pin up to six repositories, including repos from organizations you manage. Go to your profile → "Customize your pins" and select org repos.
2. **Include them in your profile README** — Link or embed any public org repository directly in this README (just like the projects above).
3. **Show contributions** — If you have access to the organization and your contributions are set to public, they will appear in your GitHub contribution graph automatically.
